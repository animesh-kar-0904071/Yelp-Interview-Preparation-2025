# Yelp Interview Preparation 2025  🚀
(attended **6 rounds** of inerviews including technical disucssions, coding and system design)


This repository contains my complete preparation journey for the Yelp Interview Process. The codes are uploaded. I chose Python and Java during proble solving.

I went through 6 rounds of interviews with Yelp. Although I was not selected in the end, I want to share my preparation openly so others can benefit from it. This repo includes coding problems, system design notes, and technical analysis exercises that I worked on while preparing.

I hope this helps anyone who’s aiming for roles at Yelp (or similar tech companies).

📖 My Interview Story

I started preparing with a mix of LeetCode-style problems, and System Design practice.

I went through 6 total rounds:

- **Round 1** – Coding

- **Round 2** – Technical Analysis

- **Round 3** (4 rounds):

  - Coding (x2)

  - System Design

  - Technical + Team Fit session

Even though I wasn’t selected, the experience was incredibly valuable. These rounds tested not just problem-solving skills but also communication, trade-off analysis, and teamwork.



🛠️ Topics Covered

 - Data Structures & Algorithms (LeetCode-style problems)

 - System Design fundamentals: Byte Byte Go(https://github.com/ani0904071/system-design-101), & Youtube channels. Major topics are mentioned below:
    -   back of the Envelop Estimation
    -   Scalability & reliability
    -   Design RESTFul APis
    -   Rate Limiting
    -   Generate Tiny URL 
    -   Caching
    -   User Content Download
    -   Geo spatial location search 

 - Behavioral and team-fit preparation
